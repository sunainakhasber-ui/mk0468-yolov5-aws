YOLOv5 Object Detection on AWS

Upload a photo. It is stored in Amazon S3, analysed by YOLOv5 in AWS Lambda through API Gateway, and the result is saved to S3 and DynamoDB.

The key is kept only in this browser (localStorage). Every API call sends it in the x-api-key header.
